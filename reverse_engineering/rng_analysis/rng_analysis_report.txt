四、核心结论
============================================================

1. 客户端 RNG 结构:
   - FixedTurnCharaSeed: 育成开始时固定的角色种子
   - RaceRandomProgramArray: 服务器预计算的随机程序数组
   - IRaceRandomGenerator: 比赛随机数生成器接口
   - SingleModeRaceRandomProgram: 单人模式比赛随机程序
   - _seedArray / s_seed: 内部种子数组

2. 种子来源:
   - 育成开始时服务器下发 FixedTurnCharaSeed
   - 比赛结果通过 RaceRandomProgramArray 预计算
   - 训练随机性由 _seedArray 驱动

3. 已有 Hook:
   - read_seed_inner(): 读取 [u32; 4] 种子
   - exec_training_hook(): 训练前后记录种子变化
   - /debug/training_seed: HTTP 端点暴露种子
   - /summary 中的 rng_seed 字段

4. 无法逆向:
   - 服务器端随机算法（Xorshift/PCG 等）不在客户端
   - RaceRandomProgramArray 由服务器预计算下发
   - 训练结果由服务器计算后返回

5. 最佳策略（已在用）:
   - 内存读取种子 → 预测训练结果 → SL 过滤
   - 不需要逆向服务器算法
   - 透视方案是唯一可行路径
