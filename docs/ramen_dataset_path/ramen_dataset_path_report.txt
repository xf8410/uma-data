三、端点行为
============================================================

步骤 1: 获取基础对象链
  WorkDataManager (singleton) → get_SingleMode → WorkSingleModeData
  → get_Character → WorkSingleModeCharaData

步骤 2: 逐个尝试 3 个 scenario getter
  - get_ScenarioRamen
  - get_WorkScenarioRamen
  - get_Ramen

每个 getter 输出:
  - method_found: bool (方法是否存在)
  - method_ptr: hex (方法指针)
  - invoke_called: bool
  - exception: hex (异常指针, 0x0 = 无异常)
  - result_ptr: hex (返回值指针)
  - result_class: string (对象实际 class 名)
  - result_namespace: string (对象实际 namespace)

步骤 3: 对非空 result 遍历 class chain (最多 8 层)
  每层输出:
  - depth: int
  - class: string
  - namespace: string
  - has_get_DataSet: bool
  - dataset_field_found: bool (<DataSet>k__BackingField 或 DataSet)
  - dataset_field_offset: int (字段偏移, -1 = 未找到)
  - dataset_invoke_ptr: hex (get_DataSet 调用结果)
  - dataset_invoke_exc: hex (异常指针)
  - dataset_invoke_class: string (DataSet 对象 class 名)

  如果 dataset_invoke_ptr 非空，停止遍历。

步骤 4: 精确查询 DataSet class
  - ns="" + "WorkSingleModeScenarioRamenDataSet"
  - ns="Gallop" + "WorkSingleModeScenarioRamenDataSet"

  输出: found bool + ptr hex

  注: metadata 显示 WorkSingleModeScenarioRamenDataSet 的 namespace 是空字符串,
  不是 "Gallop"。

步骤 5: 精确查询 ScenarioRamen class
  - ns="Gallop" + "WorkSingleModeScenarioRamen"
  - ns="" + "WorkSingleModeScenarioRamen"
