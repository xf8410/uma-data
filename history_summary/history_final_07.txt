完整失败→修复链:
  d02f8fa (引入 bug) → cbff488 (未修复) → f967668 (修复旧 bug，引入新 bug)
  → 3083922 (修复新 bug) → CI 绿

根因分析:
  1. call_getter_string() 的返回类型是 *const c_void (IL2CPP String 指针)
     但在 read_inherit_compat() 中被直接当作 String 使用
     正确用法: read_il2cpp_string(call_getter_string(...))
     证据: src/lib.rs 行 8010 函数签名 unsafe fn call_getter_string(...) -> *const c_void
            src/lib.rs 行 146 read_il2cpp_string(s: *const c_void) -> String

  2. Api struct 的可用字段 (从 CI 错误信息确认):
     log_fn, gui_show_notification_fn, gui_register_menu_item_fn,
     gui_register_menu_section_fn, hachimi_register_on_game_initialized_fn
     ... and 20 others
     不包含: il2cpp_class_get_method_from_name_fn, il2cpp_runtime_invoke_fn
     正确方式: resolve_il2cpp_symbol("il2cpp_class_get_method_from_name")
     证据: src/lib.rs 行 934, 942 已有正确用法

  3. rusqlite Statement.column_count() 返回 usize
     证据: https://docs.rs/rusqlite — column_count() → usize

  4. il2cpp_runtime_invoke 的第三个参数是 *mut c_void (exc)
     std::ptr::null() 返回 *const i32 → 类型不匹配
     正确: std::ptr::null_mut() 返回 *mut c_void
