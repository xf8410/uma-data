## 删除的污染产物

- `cook_model.onnx`：引用未上传的外部权重，无法单文件加载。
- `cook_model.pt`、`cook_model_state_dict.pt`：由错误轨迹和错误标签训练。
- `train_cook_v2.py`、`cook_game.py`：回合推进、动作标签、value、评估和角色建模均存在决定性错误。
- `cook_static_data.json`：生成说明把 `scenario_id=14`（拉面杯）误标为种田杯。
- `cardDB.json`、`umaDB.json`：大体积全量副本未被模型正确使用；重建只保留可追溯的固定配置。

## 本地卡组筛选结果

使用48套合法组合、每套相同500个完整育成种子进行规则策略筛选。当前最优组合的原始评价统计：均值 `19246.8`、标准差 `1106.3`、P10 `17721`、中位数 `19269`、P90 `20579`、最高 `22002`。评分使用 Cook2 的 `FiveStatusFinalScore[2801] + 2×技能Pt + 五星初始固有技能分`。这些是统计模拟器评价，不等同于实机稳定上限；仓库同时保留 MDB 的 `single_mode_rank` 区间，但不臆测缺失的“UE/UD + 数字”显示规则。

卡片效果来自 MDB 原始 `support_card_data/effect_table/unique_effect`。已实现包括：条件固有、Hint获得数+1（type 33）、全属性加成（type 41）、按卡组类型加成（type 120）、理事长额外羁绊（type 121）、Link收菜加成、真实得意率/友情/训练/干劲/赛后/Hint字段和候选卡事件统计。候选明细见 `support_candidates.json`。

新模型只有在完整育成轨迹、比赛回合、随机事件、角色事件、独立验证集、单文件 ONNX 和 PyTorch/ONNX 一致性全部通过后才会发布。
